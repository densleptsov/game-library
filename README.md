# Game Library

Pet project: сервис для ведения личной игровой библиотеки.

## Стек (план)
- Backend: FastAPI + SQLAlchemy
- DB: SQLite (dev) / PostgreSQL (prod)
- UI: Streamlit (или простой HTML)
- Tests: pytest + requests + Playwright
- CI: GitHub Actions
